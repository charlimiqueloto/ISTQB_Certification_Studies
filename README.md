# ISTQB CTFL Study PWA

Mobile-first offline study PWA built from the official ISTQB CTFL Sample Exam sets A-D supplied by the user.

## Run locally

Use any static HTTP server, for example: `python -m http.server 8080` inside this folder.

## GitHub Pages

Publish the folder contents as a static site.
